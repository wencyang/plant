# Illustrated botanical world

Original game assets generated with the built-in imagegen tool using the user's supplied landscape references as art direction. Source references remain external; no screenshot UI, watermarks, captions, or existing characters are incorporated.

The shared direction is fine irregular dark ink, clear flat cel shadows, a restrained sage/ochre/coral/turquoise palette, paper texture, layered stone, and unusual botanical silhouettes. The landscapes frame the interactive walkable field. Collectible plants remain separate transparent assets so individual DNA, hybrid organs, grafts, measurements and age stay visible.

Landscape files: `forest.png`, `sporefen.png`, `amber.png`, `glasshouse.png`, `coast.png`, `canyon.png`, `moonfen.png`, and `ancient.png`.

Plant files are saved non-destructively in `../plants/illustrated/`. `prompts.json` records the final prompt set and asset roles.
