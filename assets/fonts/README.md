# Chinese font

`NotoSansCJKsc-Regular.otf` is the original Noto Sans CJK SC Regular font from the Noto CJK project. It is included so Simplified Chinese works without relying on installed system fonts, including exported games.

Source: https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese
